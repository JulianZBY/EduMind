## 发现与修复

1. 本机证书链在 HTTPX 默认 CA 路径下校验失败：对话与模型清单请求加入系统信任集，保持 TLS 校验。
2. 连接、鉴权、额度、超时及异常响应原先成为泛化 500：现在返回可读且不泄露原始详情的错误。
3. 必需生成步骤异常/空结果仍被报告完成：现在先校验全部必需内容，再渲染，失败不产生空文件与空版本。
4. 空知识库下互动生成缺教学主题：传入完整教学意图；附加互动失败时明确提示，截断 HTML 不落盘。
5. JSON 解析可能返回数组/标量导致 `.get` 崩溃：入口统一只返回对象。
6. 自检脚本忽略设置库且提前装配未配置搜索：按应用启动顺序加载设置，各能力独立验收。
7. 文件名下载与版本下载的输出目录来源不同：统一读取生成目录，覆盖内联 HTML 下载回归。
