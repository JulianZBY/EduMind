# 生成物：落盘与取回

相关端点：`POST /api/v1/exam/generate`、`POST /api/v1/interactive/generate`、
`POST /api/v1/revise`、`POST /api/v1/revise/word`、`GET /api/v1/files/{filename}`。
字段与示例以 `/openapi.json` 为准；本文只解释文件名、取回方式与版本语义这三件 OpenAPI 说不清的事。

## 文件名从哪来

- 生成接口返回的 `filename` 是**落盘文件名**，只含文件名、不含目录；
  前端永远把它原样交给 `GET /api/v1/files/{filename}`，**不要自己拼路径**。
- 文件名由服务端生成（每次生成都是新名字），因此**同名覆盖不会发生**：
  「改一版」产出的新文件不会盖掉旧文件。这也是「修改产生新版本而非覆盖旧版」在文件层面的保证。
- 文件名不可反推语义（不是 `课件-第3版.pptx` 这种可读命名），
  教师看到的标题 / 版本号来自**版本记录**，不是文件名。前端不要把文件名当标题展示。

## `inline` 参数：下载还是打开

- 默认（`inline=false`）：附下载头，浏览器保存文件——用于课件、教案、提纲、试卷。
- `inline=true`：不附下载头，交给浏览器自行处理——**互动内容（HTML5）用它在新标签页直接打开试用**。
- 两类用法共用同一个端点，是因为它们取的是同一批落盘文件；差别只在响应头。

## 安全边界

文件名只允许是**单个文件名**：

- 含 `..`、`/`、`\` 一律 `400`（防止越出 `data/output` 读别的文件）；
- 目录不存在该文件返回 `404`；
- 因此前端不需要也不应该做路径拼接或路径清洗——服务端已拒绝一切带路径的输入。

## 版本与文件的对应关系

目标语义（见 ADR-0002 与票 07）：

- **每次产出都落一条版本记录 + 一个落盘文件，一一对应**。给出一个版本，就能取回那一版的文件；
  给出一个文件，就能找到它属于哪个版本。
- 同一生成物在同一会话内**版本号单调递增**；以历史版本为基线修改产出更高版本号的新版本，
  **旧版本保持可取回**。
- 「当前版本」只是版本号最高的一版，没有特殊权威；历史版本与当前版本一样可回看、可下载、可作基线。

> 实现状态：当前落盘与响应已满足「每次生成都是新文件、不覆盖」；
> **版本记录、版本列表 / 详情 / 下载接口随票 07 交付**。在票 07 落地前，
> 前端只能靠接口返回的 `filename` 记住这次产出，不能靠服务端列出历史版本。

## 生成失败时不要做的事

- `502` 表示**外部模型返回了无法使用的结果**（试卷题目解析不出来 / 互动内容不是单文件 HTML），
  此时**不会**落下半成品文件；前端应提示重试，不要把 `502` 当成「稍后再查一下进度」。
- 生成失败与「文件被清理」是两回事：文件缺失是 `404`，含义是「这个生成物不在了」。
