# 生成物：落盘与取回

相关端点：`POST /api/v1/exam/generate`、`POST /api/v1/interactive/generate`、
`POST /api/v1/revise`（课件）、`POST /api/v1/revise/word`（教案）、`POST /api/v1/revise/outline`（提纲）、
`POST /api/v1/revise/exam`（试卷）、`POST /api/v1/revise/interactive`（互动内容）、
`GET /api/v1/files/{filename}`、
`GET /api/v1/sessions/{session_id}/artifacts`、`GET /api/v1/artifacts/{version_id}`、
`GET /api/v1/artifacts/{version_id}/download`。
字段与示例以 `/openapi.json` 为准；本文只解释文件名、取回方式与版本语义这三件 OpenAPI 说不清的事。

## 文件名从哪来

- 生成接口返回的 `filename` 是**落盘文件名**，只含文件名、不含目录；
  前端永远把它原样交给 `GET /api/v1/files/{filename}`，**不要自己拼路径**。
- 文件名由服务端生成（每次生成都是新名字），因此**同名覆盖不会发生**：
  「改一版」产出的新文件不会盖掉旧文件。这也是「修改产生新版本而非覆盖旧版」在文件层面的保证。
- 文件名不可反推语义（不是 `课件-第3版.pptx` 这种可读命名），
  教师看到的标题 / 版本号来自**版本记录**，不是文件名。前端不要把文件名当标题展示。

## `inline` 参数：下载还是打开

- 默认（`inline=false`）：附下载头，浏览器保存文件——用于课件、教案、提纲、试卷。
- `inline=true`：不附下载头，交给浏览器自行处理——**互动内容（HTML5）用它在新标签页直接打开试用**。
- 两类用法共用同一个端点，是因为它们取的是同一批落盘文件；差别只在响应头。

## 安全边界

文件名只允许是**单个文件名**：

- 含 `..`、`/`、`\` 一律 `400`（防止越出 `data/output` 读别的文件）；
- 目录不存在该文件返回 `404`；
- 因此前端不需要也不应该做路径拼接或路径清洗——服务端已拒绝一切带路径的输入。

## 版本与文件的对应关系

以票 07 交付的语义为准（见 ADR-0002 与 `CONTEXT.md` 第 3 节的「版本用语」）：

- **每次产出都落一条版本记录 + 一个落盘文件，一一对应**。给出一个版本，就能取回那一版的文件；
  给出一个文件，就能找到它属于哪个版本——版本列表里每个版本都带 `filename`，
  且文件名由服务端随机生成、**同一个文件只属于一个版本**。
- 一次备课里的**同一生成物**（课件 / 教案 / 提纲 / 试卷 / 互动内容）每次产出都形成新版本，
  版本号从 1 单调递增；以历史版本为基线修改产出**版本号更高**的新版本，**原版本保持可取回**。
- 「当前版本」只是版本号最高的一版，只是列表与预览默认打开的一版，没有特殊权威；
  历史版本与当前版本一样可回看、可下载、可作基线。
- 版本之间的「由哪一版衍生而来」写在 `parent_id` 上：修改记传入的基线版本，同一生成物的再次生成
  记上一次产出，因此同一个生成物的全部版本构成一棵版本树。
- 版本由**所属备课会话**承载：生成 / 修改请求不带会话标识时维持原有语义（照旧产出文件并返回文件名），
  只是不落版本记录——无会话即无「某次备课」可归属，版本中心也就无从列出。
- 删除备课会话时，它的版本记录随会话一起删掉（与消息同一口径，不留无主版本行）；
  落盘文件不在删除范围内（本仓库尚无文件回收），也不再有任何入口能取回它们。

### 三个版本端点怎么用

| 用途 | 端点 | 说明 |
| --- | --- | --- |
| 列出某次备课的全部版本 | `GET /api/v1/sessions/{session_id}/artifacts` | 按生成物类别分组；`artifact_type` 可选过滤；组内版本号升序，含当前版本与全部历史版本 |
| 回看某一版 | `GET /api/v1/artifacts/{version_id}` | 带这一版的**内容快照**（课件 slides / 教案结构 / 提纲正文 / 题目 / 互动内容 HTML） |
| 下载某一版 | `GET /api/v1/artifacts/{version_id}/download` | 取回**该版本对应的文件**；`inline=true` 时不附下载头（互动内容在浏览器直接打开试用） |

以历史版本为基线继续修改：把 `base_version_id`（取自版本列表）随修改请求传回，或不传而只带 `session_id`
（以当前版本为基线）。**五类生成物各有自己的修改端点**（课件 / 教案 / 提纲 / 试卷 / 互动内容），
每个端点都接受同样的 `session_id` + `base_version_id`，因此 `CONTEXT.md` 第 3 节的
「历史版本一律可回看、可下载、可作基线继续修改」在五类生成物上都成立（票 08 补齐后三类）。
基线版本或会话不存在是 `404`，`base_version_id` 不是对应类别的版本（拿教案版本去改课件）是 `422`。
`GET /api/v1/files/{filename}` 仍然按文件名取文件，用于拿到文件名后的直接下载；
按版本取回请走上面第三个端点，两者取的是同一批落盘文件，差别在寻址方式（文件名 vs 版本）。

## 生成失败时不要做的事

- `502` 表示**外部模型返回了无法使用的结果**（试卷题目解析不出来 / 互动内容不是单文件 HTML），
  此时**不会**落下半成品文件；前端应提示重试，不要把 `502` 当成「稍后再查一下进度」。
- 生成失败与「文件被清理」是两回事：文件缺失是 `404`，含义是「这个生成物不在了」。
