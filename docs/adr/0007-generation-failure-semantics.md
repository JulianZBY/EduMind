# ADR-0007：必需生成失败明确报错，互动内容失败保留基础生成物并提示

- 状态：已接受
- 日期：2026-10-03
- 相关：ADR-0002、ADR-0003 修订、`docs/qa/2026-10-03-live-verification.md`

## 背景

备课编排曾吞掉课件、教案、提纲生成异常，再渲染空结构；回复仍说「已完成」。
这会把连接失败、未配置模型或不可解析输出当成可交付生成物，违背 ADR-0003 修订中的明确失败原则。
真实调用又暴露了连接错误直接返回 500、互动生成遗漏教学意图及下载目录分歧。

## 决策

- 课件、教案、提纲是本轮备课的必需生成物：全部返回可用内容后才开始落盘。
  任一失败保留异常语义：未配置为 503，供应商调用/无效输出为 502，调用超时为 504；不登记空文件版本。
- 互动内容是附加生成物：失败不丢弃成功的基础生成物，但回复必须明确提示互动内容失败。
  三条互动生成/修改路径共用完整 HTML 文档的最小校验，不保存截断网页。
- 供应商错误响应只给可操作的说明，不回显响应体、Key 或原始连接详情。
- HTTPS 保持证书与主机名校验，结合配置的 CA 集与系统信任证书；不通过关闭 TLS 校验解决连接失败。

## 后果

教师不会收到内容为空却标记完成的文件。失败与未配置可区分，成功生成物仍按 ADR-0002 保留历史版本。
必需生成并行调用中已有的成功内容在同轮其他必需生成失败时不会落盘，重试可能需要再次付费。
此检查保证最低可用结构，不承诺教学内容正确、页面排版或互动脚本运行质量；这些仍需分别验收。

## 被否决的替代方案

1. 吞掉异常并继续生成空文件：把失败伪装成成功，误导教师。
2. 同轮任意一步失败都丢弃基础生成物：附加互动失败不应阻断已成功的课件、教案和提纲。
3. 引入必需生成物部分成功协议与重试缓存：需要同时改会话状态与界面，本次修复保持既有成功响应语义。
4. 关闭证书校验：失去服务身份校验，不能作为证书连接问题的修复。
