# ADR-0008：冲突预览复用待审标题向量，显式标明不完整边界

- 状态：已接受（教师批准）
- 日期：2026-10-08
- 相关：ADR-0003、ADR-0004、ADR-0006、ADR-0007、票 08、`docs/api/conflicts.md`

票 08 要求所有真正入库的新知识点补「相关关联」，包括冲突裁决建点；只复制学科与章节不能满足此要求。教师选择复用检测已计算的标题向量，拒绝在读取冲突列表／结构预览时新增云端向量化调用。公共补边拆为纯本地候选规划与插入应用：正常入库及「接受新」「并存」「照常入库」「编辑修正后入库」共用；先完成旧点删除、关系继承与明确关系，再补边，待审、保留旧与拒绝不写图谱。

## 保存与兼容

- 检测结果在 `Conflict.new_knowledge._title_vector` 私有字段保存标题、向量及空间指纹；待审不写知识点、关系或标题索引，响应剔除此字段。
- 标题索引 `node_titles.space` 是可空元数据，幂等迁移只补列，不猜测旧向量来源。空间指纹区分实际实现、非秘密服务身份、模型、请求维度配置与实际维度，不保存 Key；服务身份归一化去除 URL 认证、查询与片段，再以指纹保存，不落原始 URL。
- 同维度不代表同空间。语义候选只比较明确同空间的标题，空间筛选和排除被替换／本条知识点在 KNN 的 top-k 之前执行。旧未知空间保留未知，不自动迁移、清空或重建。本决策只保护知识点标题索引，不改分块检索索引。

## 结构预览与失败边界

兼容信息齐全且图谱／设置稳定时，`StructurePreview.complete=true` 的终态与实际裁决一致，图示包含明确关系与计划补边端点。历史／手工冲突缺向量、标题或模型配置变化、旧未知空间或不兼容索引时，`complete=false` 并给出教师可见的中文 `reason`，只呈现可确定关系；这是对 ADR-0004 无条件完整终态承诺的教师批准例外，不改变裁决动作或检测范围。

实际裁决可重新计算本条标题，以当前能力补同空间候选；仍不把未知旧向量当成兼容向量，不承诺重建全库。sqlite-vec 标题表维度固定：不兼容时读取零向量化调用、预览不完整；建点裁决在任何图谱／旧索引写入前核对实际维度，专门的不兼容异常返回 `409`，保持待审及原点、边、来源、标题索引不变。底层标题更新写失败时，其索引事务回滚。服务／配置故障不冒充此 `409`。恢复需维护者处理标题索引，当前没有重建界面；重建另票，不引导教师点击不存在的按钮。

## 取舍

保存私有向量增加待审记录体积，但避免读取发生计费、依赖云端可用性或提前污染图谱。没有采用读取时向量化、自动重建旧索引或新增准备预览步骤／缓存／队列；代价是旧记录和模型切换后不能总给出完整预览，需要诚实提示，而不是悄悄少补边或假装全部可比较。
