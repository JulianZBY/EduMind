# 06: 文献笔记（模型 + 入库管道 + 资料详情）

**What to build:** 教师上传教学资料后，知识库区的资料详情里能看到它的**文献笔记**：资料概要
+ 由这份资料提取出的知识点索引（ADR-0007）。资料的管理入口从此落在文献笔记上。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 数据模型：文献笔记（资料概要、来源=教学资料或网页、与教学资料 1:1），
  新表进数据模型并带中文语义注释
- [ ] 入库管道：解析完成后自动生成文献笔记；知识提取完成时把该资料的知识点索引写进去
- [ ] 对话模型未配置时：分块与解析照常入库，文献笔记不生成、详情里显示「未配置」引导
  （不返回假摘要，AGENTS.md 铁律）
- [ ] 知识库区资料详情呈现文献笔记：概要 + 知识点索引列表，索引可点到知识点
- [ ] 离线测试：有对话模型替身时生成完整、未配置时引导正确
- [ ] `uv run pytest -q`、`npm run lint`、`npm run build`、`npm run check:routes` 全绿

【Ownership】
- 可改：数据模型与迁移、入库管道、documents API、知识库区前端、测试
- 禁区：删除联动（07 票范围，本票不做删除）；`app/core/asr/paraformer.py`（DashScope 史实）
