# 07: 教学资料删除联动（含路径规范化守卫）

**What to build:** 教师可以删除教学资料：删除对话框把联动后果一次交代清楚（可勾选项明确），
一次操作完成、无隐藏级联。删除规则是教师逐条确认过的（照录为验收依据）。

**Blocked by:** 06（删除规则包含「必删文献笔记」——文献笔记不存在就没得删）

**Status:** ready-for-agent

- [ ] 删除资料 API：按下列规则级联；OpenAPI 注解齐全（summary/描述/examples/错误码/tag），
  未配置相关能力时 503 契约口径不变
- [ ] **必删**：该资料的分块与向量、文献笔记、引用该资料的待审冲突（撤下）
- [ ] **知识点**：仅来源于该资料的默认删，对话框可勾选改为保留（保留者清空该来源引用）；
  多来源知识点摘除该来源、节点保留；关系边随节点走
- [ ] **被题目考查的知识点**：删除前列出受影响题目，确认后题目保留、考查关系置空
- [ ] 生成物历史版本的溯源文本不改写（史实留痕）
- [ ] 删除对话框：勾选项「同时删除仅来源于此资料的知识点（默认勾）」；被考知识点时列出受影响题目
- [ ] 路径规范化守卫：资料文件路径读写统一 POSIX 分隔符，幂等迁移进引擎迁移链
  （02 清理后存量 Windows 路径已空，此条为防御）
- [ ] 离线测试：单来源删/留、多来源摘引用、被考知识点提示与置空、冲突撤下、向量清理、
  文献笔记必删——替身+密封隔离库覆盖
- [ ] `uv run pytest -q`、前端三件套全绿
- [ ] 教师配合冒烟：上传→看文献笔记→删除→各区状态符合规则（【收尾】教师执行）

【Ownership】
- 可改：documents API、数据模型与迁移、向量库按资料清理、知识库区前端（删除对话框）、测试
- 禁区：`app/core/asr/paraformer.py`（DashScope 史实）；冲突审核的裁决动作语义（ADR-0004）；
  生成物版本表（只读）

【约束】级联不静默：对话框列出的就是会发生的全部；文案用 CONTEXT.md 词汇
（教学资料 / 文献笔记 / 知识点 / 冲突）。
